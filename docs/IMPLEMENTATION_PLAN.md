# IMPLEMENTATION_PLAN.md — 段階実装計画とマイルストーン

> 文書版: 2.0 / 2026-10-24  
> 対象: JPHACKS / 段階的開発ロードマップ

---

## 1. 段階的実装の方針

1. **逐次実行の原則**:
   一度にすべての機能を実装せず、明確に定義されたマイルストーン（M0〜M5）ごとに動作確認・テストを完了させてから次の段階へ進む。
2. **Webファースト & 段階的統合**:
   まずは Web ブラウザ上で画面遷移・モックデータ表示が完全に動作する状態を作り、その上で現場の USB シリアル実機データ受信を接続する。
3. **オフライン耐性の段階的強化**:
   SQLite によるローカルデータ永続化をベースとし、最終的にネット接続がない山林現場でも単体稼働できる状態へ段階的に到達する。

## 2. マイルストーン定義

### M0: 開発環境・品質基盤の構築 【完了】
- **目標**: Next.js と FastAPI がローカルで同時起動し、Lint / 型検査 / テストが通る環境を構築する。
- **成果物**:
  - `frontend/` (Next.js 16.4, React 19, TypeScript, ESLint, Prettier 2-space, Vitest)
  - `backend/` (FastAPI, Python 3.11, Ruff 4-space, mypy strict, pytest)
  - `AGENTS.md` (統合開発規約)
- **完了条件**: フロントエンド・バックエンドの品質チェックがオールグリーン。

### M1: 衛星地図監視ホームUI 【完了】
- **目標**: 山網の中心となる PC 向け衛星地図監視画面（`/map`）を構築する。
- **成果物**:
  - Google Maps 衛星写真ビュー + APIキー未設定/オフライン時のフォールバック表示。
  - 重要度別カラーマーカー、ポップアップ、右側警告パネル、検索、件数集計、60秒自動更新。
- **完了条件**: デモデータ（`source=demo`）でマーカー表示・警告連携・検索が滑らかに動作すること。

### M2: センサー詳細UI 【完了】
- **目標**: 個別センサーの時系列推移を確認できる詳細画面（`/sensors/[id]`）を構築する。
- **成果物**:
  - 土壌水分および傾斜角度の時系列 SVG チャート。
  - 機器状態パネル（電池、通信、ホップ数、設置座標）。
  - 地図監視・台帳一覧への戻りナビゲーション（同一タブ内遷移）。
- **完了条件**: 地図から詳細へ遷移し、グラフ描画と戻り導線が正常に機能すること。

### M3: 実証実験基盤（シリアル受信 & SQLite台帳） 【完了】
- **目標**: 現場の LoRa 集約機から USB シリアルでデータを受信し、ローカルに蓄積・管理する。
- **成果物**:
  - USBシリアル受信モジュール（S0レコード解析、破損行排除、CSV保存）。
  - 検証・オフライン用 SQLite DB（センサー台帳、状態テーブル、監査ログ）。
  - FastAPI 管理 API（`/sensors`, `/test/observations`）およびサーバー間一時トークン保護。
  - 一括起動スクリプト（`scripts/run_test_environment.py`）。
- **完了条件**: 実機シリアル入力が CSV に逐次記録され、センサー登録・編集が SQLite に永続化されること。

### M4: 実機観測・異常検知統合 【進行中 / ハッカソン最終調整】
- **目標**: 3軸加速度からの傾斜角算出、土壌水分生値の校正、しきい値超過判定を接続する。
- **タスク**:
  - [ ] 加速度（$a_x, a_y, a_z$）からピッチ・ロール傾斜角を算出する数学モジュールの追加。
  - [ ] 土壌生値（`soil_raw`）の水分パーセント換算テーブル/関数の定義。
  - [ ] しきい値超過の連続検知判定（チャタリング・単発ノイズの誤検知防止）。
  - [ ] 判定結果の SQLite 状態テーブルへのリアルタイム反映。

### M5: リアルタイムダッシュボード 【完了 / 先行実装済み】
- **目標**: 実証実験現場で受信生データを即座に確認できるダッシュボード（`/dashboard`）を提供する。
- **成果物**:
  - 3秒ポーリングによる最新500件のテレメトリグラフ（加速度、水分生値、電池mV）。
  - ノード絞り込み・期間指定・KPIタイル。
- **完了条件**: シリアル受信に合わせてダッシュボードのグラフがリアルタイムに更新されること。

### M6: 完全オフライン・プロダクション対応 【後続フェーズ】
- **目標**: クラウド回線が完全に途絶した環境でも自立する最終機能群の実装。
- **計画項目**:
  - ローカルタイルサーバーによる完全オフライン衛星写真・地形図配信。
  - 現地点検用 PWA（QRコード点検、オフラインキャッシュ、同期キュー）。
  - センサー台帳の CSV 一括インポート / エクスポート。
  - センサー論理削除 UI。
