## 1. 共通UIデザイン規約

- **レイアウト基本構造**: PC向け左固定サイドバー + メインコンテンツエリア +（画面に応じた）補助パネル。
- **カラースキーム**: 深い森をイメージした緑（`--accent`）、白/黒（`--fg`, `--bg`）、落ち着いたグレー（`--border`, `--muted`）。
- **テーマ対応**: ライトモード / ダークモードの切替対応。
- **データソース明示バッジ**:
  - `dev` モード: `source: "demo"`（「デモデータ」常設バッジ）
  - `test` モード: `source: "device_test"`（「実機検証データ」常設バッジ）
- **状態バッジ仕様**:
  - **重要度（Severity）**: `normal`（緑・正常）、`caution`（黄・注意）、`danger`（赤・危険）、`unknown`（灰・未判定）。
  - **機器状態（Device Status）**: `online`（通信中）、`offline`（通信断）、`fault`（故障）、`low_battery`（低電池）。

### 3.2 詳細操作仕様
1. **左サイドバー開閉（ハンバーガー連携）**:
   初期状態は展開表示。左上のハンバーガーボタン（`[≡]`）でワンクリック開閉。
2. **汎用パンくずリスト（Breadcrumbs）**:
   `山林一覧 > ○○山林 (第3工区)` のように動的に階層を表現。山林・工区の切替に対応。
3. **多層マップレイヤー制御（Layer Controller）**:
   情報過多を防ぐため、以下のレイヤーの表示状態（`表示` / `薄く表示 (30%透過)` / `非表示`）をボタン・トグルで制御可能。
   - **センサーレイヤー**: 🌲 樹木ノード、⛰️ 斜面ノード、異常警告ピン
   - **土地・境界レイヤー**: 私有地境界線、国有林境界、保安林
   - **現場動線・施設レイヤー**: ☕ 休憩ポイント（詰所・水場）、集材土場、作業道の轍、獣道
   - **自然・環境リスクレイヤー**: ⚠️ 危険生物（スズメバチ・マムシ・クマ出没地）、地質・破砕帯
   - **クイックプリセット**: 「災害監視モード（センサーのみ強調）」「作業計画モード（境界・道・休憩優先）」
4. **マーカーホバー（カーソルメニュー）**:
   ピンにマウスを合わせると、センサーID、名称、最新土壌水分、傾斜、重要度、通信状態をポップアップ。
5. **マーカークリック（ハイブリッドモーダル）**:
   地図上にオーバーレイで詳細ダイアログを表示。時系列SVGグラフを確認可能。モーダル内の「全画面表示 ↗」ボタンで別タブ詳細画面へ遷移可能。
6. **ノード種別アイコン**:
   - 🌲 樹木ノード（`T1`, `T2`）: 倒木・根返り・架線負荷リスク
   - ⛰️ 斜面ノード（`S1`, `S2`）: 表層崩壊・地滑り・土砂流出リスク

## 4. UI-02: センサー詳細（`/sensors/[id]`）

### 4.1 画面構成
- **ヘッダー**: センサー名称、ID、現在の重要度バッジ、機器状態バッジ、「← 地図へ戻る」または「← 管理一覧へ戻る」ボタン。
- **メイン推移グラフ（SVG）**:
  - **土壌水分推移グラフ**: 時系列での水分量変化。
  - **傾斜角度推移グラフ**: 時系列での角度変化（3軸加速度から算出）。
- **機器情報パネル**: 最終受信時刻、電池残量（mV）、通信ホップ数、設置座標（緯度・経度）。

### 4.2 画面遷移の整合性
- `?from=map` の場合は「地図監視へ戻る」導線を提供。
- `?from=sensors` の場合は「センサー台帳へ戻る」導線を提供。
- 不正なリダイレクト先を受け入れず、アプリ内の既知のルートのみに遷移を限定。

## 5. UI-03: テレメトリダッシュボード（`/dashboard`）

### 5.1 画面構成
- **最新KPIタイル**: 総受信レコード数、受信レート、稼働ノード数、最新受信タイムスタンプ。
- **生テレメトリグラフ（3秒自動ポーリング）**:
  - 3軸加速度（`ax`, `ay`, `az` [mg]）時系列折れ線。
  - 土壌生値（`soil_raw` [ADC値]）時系列折れ線。
  - 電池電圧（`battery_mv` [mV]）時系列折れ線。
- **ノード選択フィルター**: `T1`, `T2`, `S1`, `S2` など、表示対象ノードを瞬時に切替。

## 6. UI-04: センサー管理台帳（`/sensors`）

### 6.1 画面構成
- **センサー台帳テーブル**: センサーID、名称、設置緯度・経度、現在の重要度、通信状態、最終更新日時。
- **新規登録ダイアログ**:
  - センサーID（半角英数記号、重複チェック付き）
  - センサー名称
  - 設置緯度（-90〜90）
  - 設置経度（-180〜180）
  - 登録直後は「未観測」のため、状態を正常と決めつけず `unknown`（未判定）で保存。
- **編集ダイアログ**: 既存センサーの名称および設置座標の修正。変更前後の差分を監査ログへ自動保存。
