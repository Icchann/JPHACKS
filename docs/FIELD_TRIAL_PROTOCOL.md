# FIELD_TRIAL_PROTOCOL.md — 現場巡回判断支援 実証実験プロトコル・効果測定計画

> 文書版: 1.0 / 2026-10-29  
> 対象: 森林組合・林業事業体における小規模実証試験、定性・定量効果測定  
> 準拠: Issue #67, README.md §「利用場面」「今後の展望」, VALIDATION.md §6

---

## 1. 目的と位置付け

本プロトコルは、山網（SANMOU）が現場管理担当者の巡回判断（「今日、どこから現地確認に向かうか」）に与える影響を、**定性的（心理的安心感・判断の迷いの解消）および定量的（判断時間・移動工数・確認対象絞り込み率）**に検証するための実証実験手順書です。

README §「今後の展望」に基づき、**「判断にかかる時間だけでなく、設置・交換・誤警告への対応も記録し、追加された負担に見合うかを評価する」**方針を徹底し、実証前の過剰な効果断定を排除して客観的な測定枠組みを定めます。

---

## 2. 実証実験の環境設定

- **対象フィールド**: 森林組合管轄の山林工区（約30〜50ha、作業道および架線集材元木沿い）
- **対象ノード数**: 10〜30台（試作ノード T1〜T30）
- **対象参加者**: 森林組合または林業事業体の現場管理担当者 2〜3名
- **使用機材**: 現場PC（FastAPI + SQLite + Next.js ローカル稼働）、LoRa受信機（USB）、スマートフォン（現場PWA / NFC / BLE）

## 3. 比較評価シナリオ（雨・強風翌朝の点検）

荒天（前日の累積雨量50mm以上、または最大瞬間風速15m/s以上）翌朝における巡回判断業務を対象とし、同一工区・類似天候条件で以下の2シナリオを比較します。

```text
【シナリオA: 従来型巡回】
朝の事務所 ──(経験と勘で順序検討 20〜30分)──> 出発 ──(全30地点を順番に巡回 4〜5時間)──> 帰社
※ 異常が発生している場所が事前に分からず、奥地での倒木発見が後手に回るリスク

【シナリオB: 山網支援巡回】
朝の拠点PC ──(山網画面で変化地点3箇所を特定 5分)──> 出発 ──(優先地点へ最短直行 1.5時間)──> 帰社
※ 姿勢変化角・通信途絶を確認候補として即座に絞り込み、危険箇所の初動確認を迅速化
```

### シナリオA：従来手法（勘と経験に基づく全地点巡回）
1. 荒天翌朝、管理担当者が拠点に集合。
2. 前日の雨量情報や過去の記憶に基づき、どの林道から回るかを経験的に検討（所要時間測定）。
3. 軽トラックおよび徒歩で、林道・作業道沿いの全対象地点（30箇所）を順繰りに巡回・目視確認。
4. 倒木や傾斜変化を発見した場合、その場でメモし対処順序を再検討。

### シナリオB：山網支援（変化・途絶地点への優先確認）
1. 荒天翌朝、拠点または車載PCで山網（`http://localhost:3000/map`）を起動。
2. 「🌲 今日の確認推奨地点（巡回判断支援）」サマリーを開き、姿勢変化（$\ge 15^\circ$）または通信途絶が発生している確認候補地点（約3〜5箇所）を確認。
3. 優先候補地点へのアクセスルート（最短林道）を地図上で確認し、初動巡回順序を即時決定（目標所要時間: 5分以内）。
4. 優先確認地点へ直行し、現地の樹木・斜面の安全状況を目視確認。
5. 優先地点の安全確認完了後、残りの定常地点について通常巡回へ移行。

## 4. 評価指標（KPI）と測定シート

実証実験において記録する定量的・定性的な測定項目です。

### 4.1 定量的指標（Quantitative Metrics）
| 評価項目 | 測定方法 | 従来手法（想定値） | 山網支援（目標値） | 効果の判定基準 |
|---|---|---|---|---|
| **巡回計画策定時間** | 朝PC前での順序決定までの時間 | 20 〜 30 分 | **5 分以内** | 75%以上の計画策定時間短縮 |
| **初動確認到達時間** | 拠点出発から最優先変化地点への到達時間 | 120 〜 180 分 (順繰り巡回) | **30 〜 50 分 (優先直行)** | 異常地点への初動対応時間を大幅短縮 |
| **初動巡回移動距離** | 優先確認完了までの総移動距離 | 12 〜 15 km | **3 〜 5 km** | 燃料消費および悪路移動リスクの低減 |
| **確認候補絞り込み率** | 全対象に対する初動確認地点の割合 | 100% (全数確認) | **10 〜 20% (変化集中)** | 人手不足下での集中巡視の実現 |

### 4.2 定性的指標（Qualitative Metrics: 担当者ヒアリング）
5段階リッカート尺度（1: 全く思わない 〜 5: 強くそう思う）および自由記述で回収。
1. **心理的安心感**: 「どこで何が起きているか分からない状態で山に入る不安が軽減されたか」
2. **判断の確信度**: 「今朝どこから見に行くべきか、迷わず納得して出発できたか」
3. **UI視認性・使いやすさ**: 「手袋着用や車載PCの環境でも、優先確認地点が一目で把握できたか」
4. **現場業務との適合性**: 「既存の森林点検手順や天候判断ルールと矛盾なく併用できたか」

## 5. トレードオフ（追加負担）の計測枠組み

山網の導入によって新しく現場に発生する作業工数を記録し、巡回効率化の効果と差し引きして総合評価します。

| 追加作業項目 | 測定内容 | 許容基準（業務負荷上限） |
|---|---|---|
| **機体の現場設置・登録** | 樹木バンド固定、NFC識別、スマホBLE基準取得の所要時間 | **1台あたり 3 分以内** |
| **定期巡回・電池交換** | 年1回の巡回時に乾電池2本を交換する所要時間 | **1台あたり 1 分以内** |
| **誤警報（空振り）対応** | 強風による一時的揺れ等の誤警告で無駄足になった回数と時間 | **月1回以下 / 工区**（判定窓で抑制） |
| **通信途絶への調査** | 地形・樹液衰退等による不達発生時のアンテナ・中継器点検時間 | 月間総工数の5%未満 |

## 6. 安全・免責事項の遵守

実証実験の実施にあたり、以下の原則を厳守します。

1. **安全第一**: 警報の有無にかかわらず、土砂崩れや強風警報が発令されている最中には山林内へ立ち入らない。
2. **人命安全の非保証**: 山網の姿勢検知は現地確認の優先順位を決める参考情報であり、倒木事故や斜面崩壊の完全回避を保証するものではないことを参加者全員に合意する。
3. **未検証項目の開示**: 共有されたT1実機の土壌生値・電池電圧は未計測（`-1`）であり、実測ログとデモ表示を混同しない。
